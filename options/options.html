JSON 高级导入 / 备份

把上方各键的覆盖值整包备份或从别处粘贴回来，写入存储键 dwt_selectors。日常改选择器请用上面的逐行编辑；这里只适合批量迁移。

格式：一个 JSON 对象。键必须是已有选择器名（未知键会拒绝）；值为字符串，或字符串数组（多选用逗号/换行也行）。空字符串 / 空数组 = 该键回落默认。函数型键（如 sendMatch）不能写在这里。

{
  "input": ".ProseMirror",
  "userBubble": "[class*=\"bg-g-send-msg-bubble-bg\"]",
  "generatingSelectors": ["[class*=\"thinking\" i]", "[class*=\"streaming\" i]"]
}

文本框默认显示当前覆盖（无覆盖时为 {}）。改完点「导入」；导入成功后刷新豆包页生效。
